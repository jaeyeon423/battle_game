# 🎲 CIRCLE ROYALE · 원형 배틀로얄 (랜덤 무기 박스 서바이벌)

반지름 `680m`의 **원형 경기장(Circular Arena)** 에서 라운드 시작 시 화면에 뜨는 **랜덤 무기 박스(`🎁 RANDOM WEAPON BOX`)** 로 무작위 총기를 지급받아 **최후의 1인(Last Man Standing)** 이 남을 때까지 싸우는 실시간 온라인 멀티플레이 2D 도트 서바이벌 게임입니다.

> 📌 **Windows PC에서 작업을 이어가시나요?**
> 상세한 준비물, 설치 방법, 아키텍처 및 파일별 수정 가이드는 **[🖥️ WINDOWS_HANDOVER_GUIDE.md](./WINDOWS_HANDOVER_GUIDE.md)** 문서를 확인하세요!

## 🚀 Windows / Mac 공통 1분 실행 가이드

본 프로젝트는 **외부 npm 패키지 의존성이 0개(Zero-Dependency)** 이므로 `npm install` 없이 **Node.js(v18 이상)** 만 설치되어 있으면 즉시 실행됩니다.

```bash
# 1. 저장소 클론
git clone https://github.com/jaeyeon423/battle_game.git
cd battle_game

# 2. 실시간 멀티플레이 서버 실행
npm start
# 또는: node server/index.js
```

- 실행 후 브라우저에서 **`http://localhost:8080`** 에 접속합니다.
- 여러 브라우저 탭이나 다른 기기에서 동시 접속하면 같은 원형 경기장(`ROYALE-01`)에서 실시간으로 함께 대전할 수 있습니다.

## 🎮 게임 규칙 및 조작법

### 1. 핵심 규칙
1. **시작 시 랜덤 무기 박스 (`🎁 RANDOM WEAPON BOX`)**:
   - 라운드가 시작될 때마다 화면 중앙에 6종 총기 슬롯 룰렛이 돌아가며 무작위 총기와 전용 전술 스킬 2종(`Shift` / `E`)이 부여됩니다.
2. **원형 경기장 & 자기장(`RING`) 축소**:
   - 총 8명의 생존자(온라인 접속 유저 + AI 참가자)가 원형 외곽 8방향에서 출발합니다.
   - 시간이 지날수록 외곽에서 **붉은 자기장 링(`RING`)** 이 중심부(`150m`)를 향해 좁혀오며, 자기장 밖에서는 지속 피해를 입습니다.
3. **최후의 1인 (`LAST MAN STANDING`)**:
   - 적 생존자를 처치하면 **체력 `+40 HP` 회복 및 탄창 완충** 보상을 얻습니다.
   - 최후의 1명(`ALIVE: 1 / 8`)이 남으면 우승자가 발표되고, 4초 후 자동으로 다음 라운드가 시작되어 전원이 다시 랜덤 무기 박스를 추첨합니다.

### 2. 조작 방법 (PC & 모바일 가로모드 지원)
- **이동**: `W, A, S, D` 또는 방향키 (모바일: 좌측 하단 조이스틱)
- **360° 조준 및 사격**: 마우스 조준 + 좌클릭 또는 우측 하단 `FIRE` 조이스틱 드래그
- **전술 기동 스킬 1**: `Shift` 또는 `Space` (모바일: 우측 `⚡` 버튼)
- **특수 화력 스킬 2**: `E` 또는 `Q` (모바일: 우측 `💥` 버튼)
- **수동 탄창 교체**: `R` (모바일: 우측 `🔄` 버튼)
- **랜덤 무기 박스 즉시 다시 뽑기**: `B` 또는 우측 상단 `🎁 랜덤박스 다시 뽑기 (B)` 버튼
